# Mansion — ретроспектива (2026-09-23)

Особняк собран снизу вверх: элементы → агрегаты → фасады → крыша → здание.
Попутно исправлено покрытие скелетных крыш (спека v1.32, `docs/pgg/implementation.md`).
Разбор здания — `analysis.md`.

## Что шло хорошо

- **Сборка снизу вверх со стендами.** Каждый элемент и агрегат сначала показывался
  отдельно в `elements.pgg` (угловой блок, ризалиты, W5), а потом шёл в здание.
  Ошибки ловились на своём уровне: консоли эркера налезали на арку окна W8, и это
  нашлось на стенде, а не на целом доме.
- **Фасады через архитектурный слой.** `af.facades` → `lsp.split` по шаблону с кодами
  вариантов → `ls.place` в `foreach`. Два фасада с разной раскладкой собрались почти
  без возни, ширины осей меняются одной строкой.
- **Крыша на `roof_wavefront` с `@pitch = 90`.** Кровли щипцов над ризалитами, ендовы
  и вальмы — без ручной геометрии.
- **Цикл MCP «правка → кадр».** Сервер сам перечитывает изменённый файл, `pgg_probe`
  быстро даёт bbox, таблицы и промежуточные binding'и, виды лежат в `views.json`.
  Инкрементальная сборка Release — около 8 с, все тесты — около 35 с.
- **Голдены.** Сравнение фингерпринтов сразу показало, какие корпуса задела правка
  библиотеки: только якоря, геометрия крыш осталась прежней.
- **Оценка по площади.** Сравнение «площадь скатов × плотность решётки» с числом
  якорей — дешёвый и надёжный способ проверки: 804 против 806, 3672 против 3660.

## С чем пришлось возиться

1. **Покрытие крыши — главный расход сил и токенов** (по ощущениям, около половины
   работы после сборки здания). Симптом один («мало якорей»), а причин пять, и они
   лежали слоями — каждое исправление открывало следующую:
   - азимут ската ломался на точках удалённых граней;
   - сетка кандидатов строилась по длине карниза;
   - тест граничных плоскостей работал неверно на ендовах;
   - невыпуклые панели;
   - вертикальная ступенька у конька под срезом.

   Ошибка процесса: сначала был сделан обход (якоря с выпуклого контура), а в код
   `tile_anchors` полез позже. Разбивка якорей по островкам и чтение библиотеки
   сразу сэкономили бы несколько итераций.
2. **Числа однажды соврали.** На скате щипца было 126 якорей, как и положено, но
   черепицу закрывала неплоская панель — видно только на кадре. Численная приёмка
   нужна, но после неё обязателен один крупный план.
3. **Грабли языка — по круговому ходу каждая:**
   - отрицательный литерал в дефолте сигнатуры (E100);
   - `expect` только в начале тела;
   - тело def не видит top-level значений (E105);
   - повторное имя `out` (SSA);
   - у vec3-атрибута обязателен `typeinfo`;
   - нет обращения к компоненте `mid.x`;
   - `mark` присваивает членство, а `to_group` снимает группу с остальных граней;
   - `select` строит обе ветки.

   Часть уже была в cheatsheet, новое добавлено туда же («Грабли»).
4. **Ошибка движка со свесом `overhang`.** На контуре с двумя ризалитами
   `roof_wavefront` даёт вершину примерно в 130 км. Обход — ручное смещение контура
   и срез угла под шатёр (`mansion.pgg`). Не исправлено.
5. **Инструменты:**
   - пакетной пробы нет: для нескольких проб за раз пришлось писать временный
     скрипт на сыром RPC (первая попытка — неверный формат запроса);
   - якоря не несут `@island_id`: разбивку по скатам можно получить только
     временными выводами, вписанными прямо в `mansion.pgg`;
   - PggServe после пересборки C++ перезапускается вручную, после этого файлы надо
     загрузить заново (`no_file`); при заблокированном экране вместо кадров приходит
     `no_gpu`, а попытка вывести окно через osascript зависла.
6. **Нехватка встроенных функций.** Нет проверки «точка в полигоне», нет
   `raycast`/близости к мешу, нет доступа к вершинам треугольников — исправление
   невыпуклых панелей пришлось делать в C++, а не в `.pgg`.
7. **Прочее:**
   - конвенции плана (обход CCW, индексы рёбер `plan_rect`, внешняя нормаль, yaw в
     `seg_place`) приходилось каждый раз выводить руками;
   - освещение путает: скат в тени выглядел пустым — лишний кадр;
   - вида сверху нет, размеры сняты с фото по пикселям (≈ 65 px/м), часть — оценки.

## Что улучшить

| Где | Что |
|---|---|
| MCP | Пакетный `pgg_probe` (список проб за один вызов); гистограмма по атрибуту (`count by @island_id`) |
| PggServe | Сам перезапускаться при новом бинаре; внятно сообщать про заблокированный экран |
| Библиотека | `tile_anchors` пишет `@island_id` на якоря |
| Язык | Отрицательные дефолты; `delete(..., domain = faces)` с удалением осиротевших точек или агрегаты по граням; «точка в полигоне» |
| Движок | Исправить `overhang` у `roof_wavefront` и добавить тест на контур с двумя выступами |
| Процесс | При численном симптоме в общем коде — сначала разбивка по элементам и чтение библиотеки, потом обходы; после численной приёмки — один крупный план |

## Статус исправлений (2026-09-23)

Исправления делались по принципу «язык пишет LLM»: если приходилось «писать иначе», чинился
язык или текст ошибки, а не cheatsheet. Ядро оставалось домен-нейтральным, архитектурные
конвенции ушли в `lib/arch`. Спека — v1.33 (синтаксис) и v1.34 (запросы, отладка, слои).

| Проблема из ретро | Что сделано | Где |
|---|---|---|
| Отрицательный и вычисленный дефолт (E100) | Дефолты — константные выражения: `-1`, `vec3(...)`, арифметика, `[]` | спека §6.6, `validate.cpp` |
| Нет `mid.x` | Swizzle `.x/.xz/.xyz` на любом векторе и результате вызова | §6.3, §13 |
| Вызов в одну строку | Перевод строки внутри `()`/`[]` — пробел; незакрытая скобка — E101 со строкой открытия | §13 |
| Кортеж из идентификаторов, `[]` | `(x, 0, z)` → vecN, пустой список `[]` | §6.3, §13 |
| `delete` по граням оставляет точки | Осиротевшие точки удаляются (как у `extrude`) | §8.3 |
| E102/E105/E610/порядок `expect` | Подсказки называют исправление и строку | `validate.cpp`, `typecheck.cpp`, `compositor.cpp` |
| `mark` присваивает, `to_group` снимает группу | `mark(..., mode = add)`; `to_group` аддитивен | §8.6, `lib/parts` |
| Пакетной пробы нет | `pgg_probe(specs=[...])`, один прогон графа | `serve_rpc.md` |
| Разбивка по островкам — временными выводами | Инспектор `hist[attr=@island_id]`; якоря несут `@island_id`, `@part` | §9.6, `lib/arch/roof` |
| PggServe после пересборки — вручную | MCP сам перезапускает свой демон и переигрывает загрузки; про чужой — `stale_binary` | `docs/mcp_servers.md` |
| Вершина в 130 км при `overhang` | Оффсет в double с точными осевыми нормалями; тест на два ризалита; Mansion без ручного смещения | `straight_skeleton.cpp` |
| Нет «точка в полигоне», raycast | `inside_polygon`, `raycast` (BVH, ответ атрибутами) | §8.5, §8.9 |
| Конвенции плана руками | Контракт в шапке `lib/arch/plan`, `edge_frame(plan, i)`, `rect_side(side = front)`; `_` в деструктуризации | `lib/arch/plan`, §6.2 |
| Процесс: обходы раньше чтения библиотеки | Правило в `AGENTS.md` (разбивка `hist` → чтение def'а → обходы; после чисел — крупный план) | `AGENTS.md` |
| Архитектурные коды в ядре | Правило слоёв (спека §3.1, `AGENTS.md`); разнос `roof_wavefront` — отдельным шагом | §3.1 |

Не менялось осознанно: герметичность def (E105), SSA (E102), `expect` в начале тела — для
генерирующего агента это плюс; `select` строит обе ветки (семантика, в cheatsheet). Не
чинилось по решению: `no_gpu` при заблокированном экране. Не покрыто: освещение, путающее
тень со «пустым» скатом, и отсутствие вида сверху в референсах.
