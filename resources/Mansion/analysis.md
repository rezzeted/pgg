# Mansion — архитектурный разбор

Двухэтажный особняк петербургского «кирпичного стиля» конца XIX века (эклектика
с неоготическими мотивами): полуподвал, два этажа, мансарда, угловой эркер под
высоким шатром, два ризалита со щипцами. Главный приём — двухцветная лицевая
кладка: поле стены светло-палевое, все членения и обрамления —
оранжево-терракотовый кирпич, цоколь оштукатурен.

Вида сверху нет. Задние фасады не сняты — строим упрощённо (глухие стены + рядовые оси).

## 1. Объём и план

- Основной блок — прямоугольник; два уличных фасада сходятся на углу.
- **Угловой объём симметричен относительно биссектрисы угла** (с другой стороны
 эркер такой же). Неглубокий угловой выступ из обоих фасадов.
  - 1-й этаж: угол срезан, на фаске — одно широкое окно (W8), в цоколе под ним — вход в подвал.
  - 2-й этаж: эркер вынесен на двух крупных консолях (P5) по краям фаски; грани
 «боковая — диагональная — боковая»: 1 окно, 2 окна (между ними колонка), 1 окно (W3).
  - Над эркером — шатёр (P7).
- **Ризалиты со щипцами** — по одному на каждом фасаде, симметрично относительно угла.
- Композиция обоих фасадов от угла одинакова: угловой объём → одна рядовая ось →
 ризалит со щипцом → остаток фасада (входной — две рядовые оси, боковой — тройное окно).

| Фасад | Ризалит (снизу вверх) | После ризалита |
|---|---|---|
| Входной | портал P2, балкон P3 + арочное окно W2, щипец: W4 + балкончик P4 | 2 рядовые оси |
| Боковой (лестничный) | низкое широкое окно W1b, высокое окно W2 на промежуточной площадке, филёнка-розетка P6, щипец: W4 + балкончик P4 | тройное окно (3 × W1 узких на этаж) |

- Боковой ризалит — **лестничный**: окна сдвинуты по высоте относительно этажей
 (W1b низко над цоколем, W2 от 4.0 до 7.1 м — на полуплощадке), ленты C5 режутся вокруг W2.

## 2. Вертикальные ярусы

1. **Цоколь / полуподвал** — штукатурка, маленькие окна W6 (парами под широкими осями), сверху отлив C1.
2. **1-й этаж** — рядовые окна W1 в наличниках.
3. **Межэтажный пояс C2** — на нём стоят консоли эркера и балкона.
4. **2-й этаж** — рядовые W1, в ризалитах W2, на углу эркер W3.
5. **Венчающий карниз C3** — самый богатый элемент.
6. **Крыша** — слуховые окна, щипцы, шатёр, трубы.

Вертикальные членения — лопатки P1 (углы здания, границы ризалитов и углового
выступа). По стенам ризалитов — плоские оранжевые ленты C5 на уровнях подоконников и
перемычек: стена читается как решётка.

## 3. Каталог простых элементов

### Окна

| Код | Элемент | Строение |
|---|---|---|
| W1 | рядовое окно (оба этажа) | прямоугольный проём в оранжевом наличнике с лучковым (сегментным) верхом, светлый тимпан между проёмом и дугой, подоконник-полочка; переплёт — две створки + фрамуга |
| W1b | низкое широкое окно (1-й этаж бокового ризалита) | вариант W1: шире и ниже, над ним лучковая оранжевая перемычка |
| W2 | стрельчатое окно (2-й этаж ризалитов) | высокий проём со стрельчатым верхом, архивольт, импост, фрамуга по дуге |
| W3 | окно эркера | узкое высокое прямоугольное, над ним полукруглый тимпан с резным рельефом (раковина), между окнами диагональной грани — колонка с капителью |
| W4 | окно щипца | маленькое прямоугольное, выход на балкончик |
| W5 | слуховое окно | прямоугольное, трёхчастный переплёт между деревянными стойками, шиферные щёчки, плоская жестяная крыша с выносом на кронштейнах; вариант — треугольная люкарна |
| W6 | окно полуподвала | маленький квадратный проём в штукатурке, без обрамления |
| W7 | окошко шатра | миниатюрное слуховое окно со своей крышей |
| W8 | широкое окно угла (1-й этаж, на фаске) | прямоугольное, в наличнике |

### Карнизы, пояса, тяги

| Код | Элемент | Строение |
|---|---|---|
| C1 | цокольный отлив | горизонтальная полка по верху штукатурного цоколя |
| C2 | межэтажный пояс | 2–3 выступающих ряда + ряд зубчиков; огибает дом и угловой объём |
| C3 | венчающий карниз | ступенчатый напуск кирпича, зубчики, аркатурный фриз (ряд малых арок на подвесках), свес кровли |
| C4 | карниз по скатам щипца | ступенчатая лента с зубчиками вдоль наклонных краёв, кронштейны у пят, пик в вершине |
| C5 | горизонтальные ленты | плоские оранжевые полосы в плоскости стены (только цвет, без выноса) |

## 4. Агрегация (план)

- **Модуль рядовой оси**: W6 (цоколь) → W1 → W1 по одной вертикали, режется C1 / C2 / C3.
- **Ризалит** = модуль оси с заменами: W2 на 2-м этаже, P2 или W1b на 1-м, сверху щипец (C4 + W4 + P4).
- **Угловой объём**: фаска с W8 → консоли P5 → эркер из W3 с колонкой → C3 со своей аркатурой → P7.
- **Материал** — прежде всего цвет: три группы поверхности (светлый кирпич,
 оранжевый кирпич, штукатурка цоколя). Рельеф наличников и лопаток — 3–6 см;
 многоярусный вынос только у карнизов и консолей.

## 5. Масштаб

Абсолютных размеров нет. Опорная величина — высота этажа ≈ 4 м; окна выводятся
из неё по пропорциям на фото. Проверка — машина у цоколя в `side_facade_street.jpg`
(длина ≈ 4.2 м). Промер по `side_facade.jpg` (≈ 65 px/м) дал рабочие размеры
(константы — `mansion/common.pgg`):

| Величина | м |
|---|---|
| План основного блока | 15.0 (боковой фасад) × 16.3 (входной) |
| Толщина стены | 0.60 |
| Рядовая ось | 3.4 (боковой фасад), 3.0 (входной; у угла — 2.6) |
| Ризалит | ширина 4.2, вынос 0.25; щипец 60° |
| Тройное окно (боковой фасад) | 3.9, шаг окон 1.30 |
| Угловой объём | 3.0 от угла по каждому фасаду; катет фаски 1-го этажа 2.0, эркера 1.4; вынос 0.25 |
| Торцевой простенок | 0.5 |
| Отметки | верх цоколя 1.40, подоконник 1-го эт. 2.00, пояс C2 4.94, пол 2-го эт. 5.30, подоконник 2-го эт. 5.86, C3 8.80, карниз кровли 9.66 |
| Кровля | уклон 60°, подъём до палубы 4.2, свес 0.2; шатёр 5.0 над карнизом |

## 6. Порядок работы и файлы

Сначала простые элементы (W1 → C2 → W2 → C3 …) отдельными def'ами с кадром
каждого, затем агрегаты (ось → ризалит → угловой объём → фасад), затем крыша и
здание целиком на `lib/layout` + `lib/arch`.

- `mansion/common.pgg` — отметки, палитра, геометрические хелперы (`seg_place`, `plan_slab`, `cut`).
- `mansion/windows.pgg`, `belts.pgg`, `details.pgg` — элементы: окна, карнизы и лопатки, консоли/портал/балконы/розетка.
- `mansion/units.pgg` — агрегаты: `axis_bay`, `triple_bay`, `end_pier`, `risalit_side`, `risalit_entr`, `gable`, `corner_block`, `turret`, `w5`.
- `elements.pgg` — стенды элементов и агрегатов (кадр каждого).
- `retrospective.md` — что шло хорошо и на что ушли силы при сборке.
- `mansion.pgg` — здание: фасады раскладкой `lib/layout/split` по рёбрам `plan_rect`, крыша `roof_wavefront` (фронтоны щипцов — `@pitch = 90`), шифер по `tile_anchors`, слуховые окна, трубы, водостоки. Виды — `mansion.views.json`.
