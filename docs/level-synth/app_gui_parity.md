# Паритет приложения LevelSynth с Edgar.GUI

Краткое сравнение сценариев **оригинала** (WinForms/WPF Edgar.GUI в Edgar-DotNet) и **порта** (SDL3 + ImGui, `main.exe`).

## Что делает оригинал

- Работа с деревом ресурсов: `MapDescriptions`, `Maps`, `Rooms`, `Images`, `RandomGraphs` и т.д.
- Выбор карты из списка, предпросмотр, генерация, экспорт.
- Полноценный редактор и навигация по файлам в стиле IDE.

## Что делает порт (текущее состояние)

- **Корень ресурсов:** по умолчанию ищется `resources/edgar_gui` с подпапками `Maps/` и `Rooms/` (обход каталогов вверх от `main.exe`, чтобы работать из `_build/bin/...` в клоне репозитория).
- **Список карт:** только файлы **`Maps/*.yml`** и **`Maps/*.yaml` на верхнем уровне** (без рекурсии в подпапки). Выбор в **выпадающем списке**, кнопка **Reload catalog**, в интерфейсе отображается текущий путь к ресурсам.
- **Один файл из CLI:** аргумент с путём к `*.yml` / `*.yaml` — загрузка этой карты и вывод базовой папки из пути.
- **Drag-and-drop:** на окно можно сбросить папку с `Maps/` и `Rooms/` (корень `edgar_gui`) или путь к файлу карты.
- Генерация и предпросмотр раскладки, экспорт JSON в выбранный файл (на Windows — диалог сохранения из меню **File → Export JSON**).
- Сообщения об ошибках загрузки YAML/файловой системы — в панели лога.

## Пробелы (намеренно вне скоупа)

- Не клонируется полный UI WPF (списки с миниатюрами, отдельные окна редактора).
- Отдельного диалога «открыть файл» для выбора карты нет — используется комбо по каталогу `Maps/` и опционально CLI/drag-and-drop.
- Unity / Unity build не рассматриваются.

## Командная строка

- `main.exe <path\to\map.yml>` — загрузить одну карту; база выводится из пути (`…/Maps/name.yml` → родитель `edgar_gui` или эквивалент, см. реализацию в `preset_loader.cpp`).
- Флага `--resources` в текущей версии нет: корень задаётся автопоиском, drop или загрузкой через путь к `.yml`.

## Ручной чек-лист (регрессия UX)

1. Запуск без валидного `resources/edgar_gui` рядом с exe — fallback на встроенный 4-room cycle, сообщение в логе.
2. Нормальная копия `resources/edgar_gui` — список карт не пустой, генерация работает.
3. Запуск с путём к одному `Maps/foo.yml` — каталог строится от этого файла.
4. Export JSON — файл появляется по выбранному пути (Windows: диалог «Сохранить»), в логе полный путь; отмена диалога — сообщение об отмене.
5. Ошибка: несуществующий путь — текст ошибки в логе (`Load error: …`), без молчаливого пустого каталога.
6. Перетаскивание `.yml` / `.yaml` или папки `edgar_gui` на окно — загрузка карты или каталога (SDL drop).
