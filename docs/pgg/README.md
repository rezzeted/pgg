| `art_session_workflow_plan.md` | **План доработок по итогам арт-сессий `spire_house` (правки готового) и `inn_hotel` (постройка с нуля)** — stateless render и эхо состояния вьювера (липкие `wire`/`ortho`/`target` читаются как свойство модели), cheatsheet + rule для авторинга, вынос архитектурных хелперов в `lib` (многоугольники, подрезка кладки по проёмам, черепица/коньки, скруглённый план и гнутые детали), именованные виды и контакт-лист в viewer, измерения bbox/gap через `pgg_probe`, `select`/`empty_mesh` в ядре, порядок работ «масса → форма → палитра» и правила проверки регрессий |
| `mc_thin_shell_slivers.md` | **Расследование (закрыто, v1.24.2):** marching-cubes плавни-«бахрома» на тонкой оболочке призм — симптом, репрокейс, найденный корень (грань примитива ровно на узлах решётки `mesh_from_sdf`), фикс и тест |
| `viewer_rpc.md` | **Контракт `PggViewer --serve` + MCP `pgg`** — порт 9878, операции (load/params/render/views/probe/export/docs), stateless render + `render_state`, именованные виды, грабли (синхронный render, no_frame_loop, лок экрана), автоподнятие viewer'а |

Код: `src/libs/pgg` (библиотека), `src/apps/PggTool` (CLI), `src/apps/PggViewer` (нодовая проекция + превью), `src/tests/pgg` (тесты + корпус эталонов `.pgg`), `resources/pgg` (продуктовые/арт-примеры `.pgg` с модулями `lib/` и `cottage/`).
